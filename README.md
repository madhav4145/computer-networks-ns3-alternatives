
# Computer Networks Simulation — NS-3 Alternatives

## Overview

This project contains five browser-based Computer Networks
simulation demonstrations developed using HTML, CSS, and
JavaScript.

The project provides lightweight, visual alternatives for
learning selected networking concepts without installing NS-3.

## Simulations

1. **Congestion Control** — Visualizes congestion-window
   changes and simulated packet loss.
2. **TCP Packet Transmission** — Animates data packets and
   acknowledgements.
3. **UDP Packet Transmission** — Demonstrates datagram flow.
4. **Distance Vector Routing** — Demonstrates routing-table
   updates and distance calculations.
5. **Link State Routing** — Demonstrates link-state routing
   and shortest-path calculation.

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Web browser

## Requirements

- Google Chrome, Microsoft Edge, Firefox, or another modern
  web browser.
- No NS-3 installation or external JavaScript libraries
  required.

## How to Run

1. Download or clone this repository.
2. Open the required `.html` file.
3. Run it in a modern web browser.
4. Use the simulation controls to start, pause, or reset
   the animation.

## Project Structure

The repository contains five standalone HTML files and
screenshots of their outputs.

## Limitations

These are educational browser-based demonstrations.
They do not reproduce all protocol behavior, timing,
packet-level events, or performance measurements of a
real NS-3 simulation unless explicitly implemented.
